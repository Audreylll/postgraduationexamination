# 2010-2025 考研英语一真题精读

直接双击 `index.html` 即可离线使用，无需安装依赖。

## 功能

- 2010-2025 英语（一）真题统一年份与题型导航
- 2021、2023 使用用户重新提供的 DOCX 文字版，不再用整页图片代替正文
- 点击任意英文单词自动朗读，并在完整词典卡中显示音标、词性、语境义、常用中文义、英文解释、经核对的搭配以及中英对照真题例句
- 段落级语境译文；重点词与重点短语使用两种配色标亮
- 2010—2025 正文段落均带有按整段语境生成的中文参考译文；正文下方的逐词释义最多显示 3 个短义项
- 长难句解析默认收起，可按需查看结构切分、连接信号和理解顺序
- 单词星标收藏到本地生词本
- 阅读理解答案与原文定位
- 完形填空按真题顺序逐题排列，每题固定为 A、B、C、D 四栏；可在题目上方或顶部一键显示全部选项中文
- 完形正文与段译不再重复显示嵌入文末的 1—20 题选项，选项只保留在下方的 A、B、C、D 四栏表格中
- 翻译参考答案、写作范文与解析原页按需展开
- 可勾选生词并按“英译中”或“中译英”生成 A4 默写卷，参考释义页可选
- 艾宾浩斯背词模式按 1、2、4、7、15、30 天安排复习，自动朗读并引用真题例句
- 网页默写支持键盘输入与鼠标/触控笔手写板；任意勾选生词可按顺序连续朗读
- 内置真题离线音标库，覆盖 8,313 个词形；同时内置 10,142 条与真题语料匹配的词语记录，离线提供词性、常用义和英文释义
- 每段下方的搭配区默认收起，可单独展开某一段，也可从顶部一键展开或关闭当前篇章的全部搭配；内容统一采用“英文短语：中文释义”格式

## 导出生词默写 PDF

1. 点击正文单词，再点弹窗右上角星标收藏。
2. 在右侧生词本或导出窗口勾选所需单词。
3. 点击顶部“导出生词默写 PDF”，选择默写方向及是否附参考释义。
4. 在系统打印窗口中选择“另存为 PDF”。

参考释义按原选择顺序竖向排列。生词与复习进度只保存在当前浏览器的本地存储中。

## 2021、2023 年说明

2021、2023 年正文已改用用户新提供的 DOCX，题干、文章、完形选项、翻译和作文题目均为可点击文字。2023 DOCX 未包含 Part B 漫画，因此不展示未经原图核实的大作文范文。

2011—2021 年解析资料中，部分文件没有可靠文字层。网站对这些年份保留解析原页，不用不稳定 OCR 代替正式答案；2022 年翻译与写作答案、2024 年翻译答案则以可复制文字展示。2024 年解析文件注明写作“答案略”，站内范文为根据原题另行编写的参考版本。

## 朗读说明

朗读使用浏览器内置英文语音。真题常见词的音标可离线显示；只有离线词库未收录的词才会联网查询并缓存。若无声音，请在 Windows 系统设置中安装英文语音包，或改用最新版 Edge / Chrome 打开。

离线音标数据节选自 [open-dict-data/ipa-dict](https://github.com/open-dict-data/ipa-dict)；离线词性、中英释义与短语数据节选自 [ECDICT](https://github.com/skywind3000/ECDICT)。本项目仅保留与站内真题语料相关的记录；未收录词仍可联网查询并缓存。
